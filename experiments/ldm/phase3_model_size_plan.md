## 评估策略

**训练**：直接跑确定的最优 epochs，ckpt_interval = epochs（只保存最终 + best）

**评估**：对最终 best.pt，生成 50 张样本，计算 **全部 6 指标**：
- FID、KID、LPIPS、BRISQUE、PRD_F8、PRD_F1/8

**判断标准**：
- 质量：FID/KID 越低越好
- 多样性：LPIPS 越高越好
- 清晰度：BRISQUE 越低越好
- 覆盖率/精确率：PRD_F8 / PRD_F1/8 越高越好
- 效率：参数量 vs 质量 trade-off

---

## 预期结果

| 场景 | 预期 |
|------|------|
| 128 优于 192 | 小模型足以拟合数据集，大模型浪费且易过拟合 |
| 192 最优 | 当前参数刚好匹配数据复杂度 |
| 256 最优 | 数据集需要更大容量，当前模型欠拟合 |
| TIGHT 128 最优 | 小数据集应配小模型，防过拟合 |
| LEAK 256 最优 | 大数据集可容纳更大模型 |
